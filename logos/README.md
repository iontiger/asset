# 로고 이미지

이 폴더에 자산 로고 이미지(png · jpg · jpeg · webp · svg · gif)를 넣고 푸시하면
GitHub Pages에 함께 배포되고, 로고 선택 창이 읽는 `logos.json` 목록도 자동으로 만들어집니다.
(예전의 `update-logos.sh` 는 필요 없습니다)

GitHub 웹에서 올리려면: 이 폴더 화면에서 **Add file → Upload files** 로 이미지를 끌어다 놓고 커밋하세요.

파일 이름은 자산 데이터의 `logo` 값과 같아야 합니다 (예: `kb-bank.jpg`, `토스.png`).
확장자는 데이터에서 생략해도 됩니다.
