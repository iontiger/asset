# 마을 건물과 랜드마크

참고 페이지: https://iontiger.github.io/asset/3d/ (2026-10-02 확인)

참고 페이지는 GLB/GLTF 다운로드 목록이 아니라 Three.js로 건물과 지형을 만드는 마을입니다. 해당 페이지에서 확인한 형태·색·이름을 바탕으로 이 게임용 모델을 `village-landmarks.js`에 구성했습니다. 원본 페이지의 전체 앱이나 자산 데이터, 계정 기능은 가져오지 않습니다.

## 반영한 디자인

| 게임 요소 | 참고 페이지에서 확인한 특징 |
| --- | --- |
| 주택가 | 크림/살구색 벽, 녹색/붉은 박공지붕, 십자 창틀, 화분, 발코니, 굴뚝 |
| 작은 상점 | 초록 지붕, 전면 기둥, SHOP 간판 |
| 상점가 | VILLAGE MARKET 간판, 네 기둥과 계단, 짙은 녹색 지붕 |
| 중앙 나무 분수 | 원형 석재 광장, 청록색 물, 가운데 작은 나무 |
| 보물 창고길 | 녹색 금고, 금빛 손잡이와 동전 |
| 억 돌파 석탑 | 층층이 작아지는 사각 석탑, 금빛 띠와 꼭대기 장식 |
| 오래오래 낚시터 | 작은 호수, 나무 부두, 의자와 낚싯대 |
| 바위섬 등대 | 빨강/흰색 줄무늬 원통, 난간과 등불 |
| 열기구 | 주황색 기구, 금빛 띠, 매달린 바구니 |

7개 주요 장소는 주행 순서에 따라 이름표, 거리 안내, 방문 알림, 미니맵 표시와 연결됩니다. 보통 주택은 코스 전반에 반복 배치됩니다. 원본 마을 전체의 위치를 복사한 것이 아니라 기존 7.2 km 주행 코스에 맞춘 배치입니다.

현재 버전은 모델을 실제 Three.js Mesh와 Group으로 월드에 배치합니다. 주행 카메라의 원근·조명·그림자가 실시간 적용되며, 원본 사이트에 접속하지 않습니다. WebGL이 필요하며, 미지원 환경에서는 안내 화면을 표시합니다. 이전 이미지 스프라이트 변환 방식은 사용하지 않습니다.
