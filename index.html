      데이터 폴더 다시 연결

      폴더의 asset-data.json 을 이어서 씁니다. 브라우저 보안 정책상 새로 열 때 폴더 접근을 한 번 허용해야 합니다. 권한 창에서 "방문할 때마다 허용"을 고르면 다음부터는 묻지 않습니다.

      설정

      데이터 파일

      모든 기록은 고른 폴더 안의 JSON 파일 하나에 저장됩니다. 서버나 계정 없이 이 PC에만 있습니다.

      고른 폴더 ├ asset-data.json ← 자산 기록 · 소유자 · 설정 ├ backups\ ← 하루 한 번 자동 백업 (최근 30개) └ logos\ ← 로고 이미지 (선택)

      OneDrive · Google Drive · Dropbox 폴더를 고르면 PC 여러 대에서 같이 쓸 수 있어요 — 방법 보기

      이 브라우저는 PC 폴더에 직접 저장하는 기능(File System Access)을 지원하지 않습니다. Microsoft Edge 나 Chrome 으로 열거나, "브라우저에 저장하기"로 쓰면서 JSON 내보내기로 백업하세요.

      백업 · 가져오기

      JSON으로 내보내거나 JSON/CSV 파일을 가져와 합칩니다 (같은 날짜·이름은 덮어씀). Supabase에서 내보낸 assets · owners CSV도 그대로 가져올 수 있습니다.

      클라우드 연동 ?

      기본은 PC 파일입니다. 여러 기기에서 같이 쓰려면 Supabase 나 Google Sheet 중 한 곳을 저장소로 연결하세요.

      기록은 위 데이터 파일에서 고른 폴더의 asset-data.json 에 저장되고, 매일 backups 에 자동 백업됩니다. 인터넷 없이도 동작해요.

      PC 여러 대에서 쓰려면 — 동기화 폴더에 두기 (설정 필요 없음)

      1. PC에 OneDrive(윈도우 기본) · Google Drive 데스크톱 · Dropbox 중 하나가 로그인돼 있는지 확인합니다.
      2. 그 동기화 폴더 안에 폴더를 하나 만들고 (예: OneDrive\자산현황), 위 폴더 선택으로 고릅니다.
      3. 다른 PC에서도 같은 폴더를 고르면 같은 기록을 봅니다. 한쪽에서 저장하면 몇 초~몇 분 뒤 다른 PC에 동기화되고, 창으로 돌아올 때 자동으로 다시 불러옵니다.
      • PC끼리만 됩니다 — 휴대폰 브라우저는 폴더 저장을 지원하지 않아요 (휴대폰도 쓰려면 Supabase · Google Sheet).
      • 두 PC에서 동시에 고치지 마세요. 한쪽에서 저장한 뒤 동기화가 끝나면 다른 PC에서 이어서 쓰세요.
      • 동기화 앱이 asset-data-PC이름.json 같은 충돌 사본을 만들면, 맞는 쪽을 남기고 지우세요 (backups 에도 매일 사본이 있어요).
      • OneDrive는 그 폴더를 "이 디바이스에 항상 유지"로 설정해 두면 오프라인에서도 바로 열립니다.
      1. supabase.com 에서 무료 프로젝트를 만듭니다 (예전 모바일 버전 프로젝트를 그대로 써도 됩니다).
      2. 아래 SQL 복사를 누르고, Supabase SQL Editor → New query 에 붙여넣어 Run. 예전 모바일 버전 프로젝트(owners · assets)는 건너뛰어도 연결됩니다 — 그때 목표 · 뱃지 · 연금 포트폴리오는 이 브라우저에 저장돼요.
      3. Project Settings → API(또는 API Keys)에서 Project URL 과 anon · publishable 키를 복사해 아래에 넣고 연결.
      1. 구글 시트를 새로 만들고 확장 프로그램 → Apps Script 를 엽니다.
      2. 아래 Apps Script 복사를 눌러 기존 코드를 지우고 붙여넣은 뒤 저장. 맨 위 TOKEN 에 비밀 문자열을 넣어 두길 권해요.
      3. 배포 → 새 배포 → 웹 앱, 실행: 나, 액세스: 모든 사용자 → 배포 (처음엔 권한 허용).
      4. 나온 웹 앱 URL(…/exec)과 토큰을 아래에 넣고 연결.

      소유자 관리

      이름을 바꾸면 기존 기록에도 바로 반영되고, 삭제하면 해당 소유자의 자산은 "미지정"이 됩니다.

      축하 효과

      순자산이 천만원 단위로 새 기록을 세우거나 억 단위를 넘을 때, 목표의 10%씩 다가갈 때, 대출이 천만원 단위로 줄 때 화면 효과로 축하해 드려요. 같은 기록은 한 번만 축하합니다.
