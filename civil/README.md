# 덴포토 치과 경쟁 (DentPhoto Clinic Wars)

DentPhoto 마을 3D(`3d/`)의 **치과 경쟁 본부**에서 들어가는 턴제 전략 게임입니다. 따로 열어도 됩니다: https://iontiger.github.io/asset/civil/

덴포토 치과를 열고 지점을 늘려 동네 상권에서 경쟁 치과 2~4곳과 겨룹니다. 지도 크기로 경쟁 치과 수가 정해집니다(작게 2 · 보통 3 · 크게 4).

| 치과 | 특성 |
|---|---|
| 덴포토 치과 (우리) | 정직 진료 — 매출 +10%, 지점 평판이 빨리 회복 |
| 덤핑치과 | 반값 스케일링 — 환자 +35%, 매출 −30% |
| 불법위임치과 | 진료력 +30%, 대신 가끔 보건소 단속(벌금 · 평판 하락 · 영업정지) |
| 365치과 | 연중무휴 — 진료력 · 연구 +15%, 평판 회복 빠름 |
| 광고폭탄치과 (크게) | 매출 +30%, 연구 −25% |

- 자원: 🙂 환자 · ⚙ 진료력 · 💰 매출 · 🔬 연구. 지점 규모는 체어 수, 지점 체력은 평판.
- 직원: 개원팀 · 인테리어팀 · 홍보 오토바이 · 치위생사 · 블로그 마케터 · 보험청구팀 · 광고 차량 · 보존과 전문의 · 현수막 부대 · 응급 앰뷸런스 · 임플란트 전문의 · TV 광고.
- 시설: 대기실 확장 · 의료분쟁 법무팀 · 디지털 기공실 · 예약 문자 센터 · 세미나실 · 소아치과 · 구강 스캐너 · 사진실 · 임상 연구소 · 경영지원실 등. 랜드마크: 키즈 분수 정원 · 덴포토 강변 등대 · 목표봉 전망 치과 · 억 돌파 석탑 · 풍선 축제.
- 승리: 🏥 인수 합병(경쟁 치과 본점을 모두 인수) · 🏆 목표자산 20억(마지막 연구 '자산 경영' + 매출 2,000) · ⭐ 평판 점수(250턴).
- 지점 건물은 `../3d/ride/vendor/three.min.js`(Three.js r160)와 `../3d/ride/village-landmarks.js`의 마을 3D 모델로 짓습니다.

## 파일
- `civ-rules.js` — 화면 없는 규칙(육각 지도 · 지점 · 직원 · 경쟁 · 연구 · 관계 · 경쟁 치과 AI · 특성 · 승리 · 저장). node 에서도 돕니다. 코드 안의 이름(city · unit · gold …)은 그대로 두고 화면 글자만 치과 말로 씁니다.
- `civ-view.js` — Three.js 화면(지형 · 자원 · 상권 경계 · 지점 · 직원 모델 · 안개 · 애니메이션). 지점과 직원은 조각을 메쉬 하나로 구워 그리기 횟수를 줄입니다.
- `civ-game.js` — 조작(누르기 · 끌기 · 확대 · 단축키), 직원/지점/연구/경쟁 치과 화면, 턴 진행, 자동 저장.
- `civ-test.cjs` — `node civ-test.cjs`: 컴퓨터끼리 세 가지 지도 크기로 끝까지 두며 규칙이 깨지지 않는지 봅니다.

## 마을과 잇기
`3d/src/civ.js`가 마을에 치과 경쟁 본부를 세우고, 문 앞에 가면 이 페이지를 전체 화면 iframe 으로 엽니다. 게임은 `postMessage({dpCiv:'close'})`로 마을에 돌아가고, 이기면 `{dpCiv:'finish',win:true}`를 보냅니다. 저장은 `localStorage['dentphoto-civ-v2']`, 기록은 `['dentphoto-civ-record-v1']`.

## 시험
- `?quick` — 시작 화면 없이 바로 새 게임(`&seed=`, `&size=small|normal|large`)
- `window.civDebug` — `S`(상태) · `C`(규칙) · `view` · `endTurn()` · `select(u)` · `openCity(c)`
